Difference between .. and ...                                        2026-10-29
-------------------------------------------------------------------------------

In branch comparison, e.g.:

  origin/main..HEAD             Latest main vs. latest feature branch
  origin/main...HEAD            Common anvestor vs. latest feature branch

Before merging, use ... to see changes introduced by feature branch, without
all the changes made on main.


cherry-pick -x                                                       2026-10-13
-------------------------------------------------------------------------------

When cherry-picking, use the `-x` flag to append the original commit SHA to
the commit msg, which will be easier for referencing.

  cherry-pick -x [commit-sha]
